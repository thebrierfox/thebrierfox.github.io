"What's the highest risk-adjusted yield available right now — and how should I reweight my portfolio to capture it?"
What it does

YIELD INTELLIGENCE is a free MCP server that connects Claude to live passive income data. Ask your AI assistant about Treasury yields, portfolio optimization, or passive income strategy — it pulls live data and runs the analysis inside Claude.

No payment. No API key. One URL.

Two tools
analyze_yield_opportunities Scans the current yield landscape — live Treasury rates (4-week through 30-year), I-Bonds, TIPS, corporate bond benchmarks, and dividend categories. Returns a ranked opportunity set with risk-adjusted return profiles.
optimize_income_portfolio Takes your current holdings and income target, runs an optimization pass against live rates, and returns rebalancing recommendations with projected yield improvement.
How to connect
Method 1 — Claude Desktop config

Add to your claude_desktop_config.json:

{ "mcpServers": { "yield-intelligence": { "url": "https://api.intuitek.ai/yield/mcp" } } }

Restart Claude Desktop. YIELD INTELLIGENCE appears in your tools panel.

Method 2 — MCP Registry

Search "YIELD INTELLIGENCE" in Claude Desktop → Settings → Manage MCPs. Listed under io.github.thebrierfox/intuitek-ace on the official MCP Registry.

Live data. Treasury rate data pulled directly from TreasuryDirect.gov. No cached snapshots. Every analysis reflects current market conditions at the time of the query.
